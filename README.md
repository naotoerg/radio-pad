# Radio Pad

iPadのホーム画面に追加して使える、ラジオ収録向けのシンプルなサンプラーです。

## 起動

Finderで `Radio-Padを起動.command` をダブルクリックします。

または、ターミナルから次を実行します。

```sh
cd /tmp
python3 -m http.server 8080 --bind 0.0.0.0 --directory "/Users/kob/Documents/_OnGoing/dmj2026/soundplayer"
```

ブラウザで `http://localhost:8080` を開きます。iPadに入れる場合はHTTPSで公開し、Safariの共有メニューから「ホーム画面に追加」を選びます。

## 使い方

- 「音を追加」から音声ファイルを複数選択できます。
- パッドを押すと即座に再生し、再生中の音がある場合は切り替わります。
- `•••` から名前とランダムグループを設定できます。
- 同じグループ名を付けた音源から、ランダムで1つだけ再生できます。
- 音源は端末内のブラウザ保存領域に保存されます。
