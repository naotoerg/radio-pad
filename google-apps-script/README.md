# Googleフォーム回答の接続

1. 回答スプレッドシートを開き、`拡張機能` → `Apps Script` を開きます。
2. `コード.gs` の内容を、このフォルダの `Code.gs` の内容で置き換えて保存します。
3. 上部の関数選択で `setupAccessToken` を選び、`実行`します。初回だけGoogleの認証を許可します。
4. 実行ログに表示された長いアクセスキーを控えます。
5. `デプロイ` → `新しいデプロイ` → 種類を`ウェブアプリ`にします。
6. `次のユーザーとして実行`は`自分`、`アクセスできるユーザー`は`全員`にしてデプロイします。
7. 表示された `/exec` で終わるウェブアプリURLを控えます。
8. Radio Padの`お便り` → `接続設定`を開き、URLとアクセスキーを保存します。

URLとアクセスキーはRadio Padを開いた端末内にのみ保存されます。アクセスキーをGitHubへ書き込まないでください。
